# 💉 H1N1 Vaccine Prediction using Logistic Regression

A Machine Learning project that predicts whether a person is likely to receive the **H1N1 vaccine** using **Logistic Regression**.

The project was developed using Python and Jupyter Notebook and deployed as an interactive web application using **Streamlit**.

---

## 📌 Project Overview

The goal of this project is to predict H1N1 vaccination based on different demographic and behavioral characteristics of individuals.
